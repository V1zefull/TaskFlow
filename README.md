# TaskFlow

Pet-проект менеджера задач на React, TypeScript и Vite.

## Требования

- Node.js 22.13.0 (версия закреплена в `.nvmrc`)
- npm 10 или новее

## Локальный запуск

```bash
nvm use
npm ci
npm run dev
```

## Проверки

```bash
npm run check
npm audit
```

`npm run check` последовательно запускает ESLint, TypeScript и production-сборку Vite.
